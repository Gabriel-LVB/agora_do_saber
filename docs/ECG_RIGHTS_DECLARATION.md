# Declaração operacional de origem e uso dos ECGs

> Registro de contexto do projeto, confirmado pelo responsável pelo Ágora do Saber em 30 de julho de 2026.

O responsável pelo site confirmou expressamente que:

- o material do pacote `Agora_ECG_import_staging_v3.zip` é material próprio;
- o Ágora do Saber possui autorização para utilizá-lo no site;
- as imagens dos ECGs podem ser entregues por URLs públicas do site;
- a referência a “Hampton” ou “Hamptom” surgiu de uma confusão/alucinação de uma IA e não descreve a origem real do material.

Esta confirmação substitui, para fins operacionais do projeto, a hipótese de proveniência registrada durante a auditoria da v2.

## Uso no produto

- O pacote original contém casos clínicos, diagnósticos, achados, condutas e respostas completas fornecidos pelo responsável.
- Esse gabarito fornecido é a fonte canônica da experiência no site; não há uma etapa adicional de “revisão clínica independente” exigida para a aba existir ou para o material ser estudado.
- A interface revela a resposta somente após ação do usuário para preservar a dinâmica de estudo, embora os arquivos sejam públicos por decisão do proprietário.
- A autorização de uso no Ágora não é apresentada como licença para redistribuição por terceiros.
